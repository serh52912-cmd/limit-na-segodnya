# Лимит на сегодня

Адаптивное веб-приложение для планирования ежедневного бюджета.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере (Chrome, Safari, Edge).
3. Перейдите в «Настройки» и введите баланс, обязательные платежи, сумму накоплений и количество дней до следующего дохода.

## Разделы
- Обзор — безопасный дневной лимит, прогресс и сводка.
- Расходы — добавление и удаление расходов.
- Цели накопления — создание целей и пополнение.
- Аналитика — суммы по категориям и распределение бюджета.
- Настройки — параметры расчёта и режим экономии.

## Важно
Данные сохраняются локально в браузере через localStorage. Приложение не подключается к банковским счетам и не отправляет данные на сервер. Для командной демонстрации используйте один и тот же браузер/устройство либо заполните данные заново.

Формула:
(Баланс − обязательные платежи − сумма накопления) / количество дней.
Режим экономии дополнительно уменьшает дневной лимит на выбранный процент.
